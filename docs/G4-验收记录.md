### 首次打开 = 空窗恢复（代码评审结论）

恢复只有一处实现：`TuiApp.rebuildFromHistory`。三个入口都汇到它：

- **首次打开 / 切换会话**：`subscribeStreams` 以水位 0 调它（渲染全部历史）；
- **空窗（GAP）**：`onGap` 以当前水位调它（只补缺失段）；
- **断线重连**：`attachStreams` 不预拉历史 —— 窗口内靠重放 + `SeqRule` 去重收敛，
  超窗时首帧序号跳变自然落入 `onGap`，仍是同一条路径。

`SeqRule` 的类注释同时钉住了这一点：本地最大 = 0 时首帧必然判 GAP，
**调用方不需要（也没有）区分"第一次"与"断了很久"这两种情况。** 不是两个分支。
