# TODO 目录

本目录按《开发规划.md》的阶段保存待办事项，每个阶段使用独立目录：

```text
todo/
├── P0-地基/
│   └── TODO.md
├── P1-单节点闭环/
│   └── TODO.md
└── ...
```

当前仅创建已经完成代码审查、且存在明确未完成项的阶段目录。后续阶段经过审查后，再增加对应目录和 TODO 文件，避免把尚未核实的规划任务直接标记为代码缺口。

## 使用规则

- 一个阶段的所有待办统一记录在该阶段的 `TODO.md` 中。
- 待办使用 `- [ ]`；完成并通过验证后改为 `- [x]`。
- 每项必须注明完成标准，不能只记录实现动作。
- 前一阶段门禁未通过时，不应勾选依赖该门禁的后续阶段任务。
- TODO 与实现发生偏差时，应同步更新《开发规划.md》或记录正式决策。
